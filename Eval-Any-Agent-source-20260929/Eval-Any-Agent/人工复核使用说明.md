# 人工复核怎么用

2026-09-30，本机评测工具已补齐人工复核入口。

直接打开 [本次评分结果](http://127.0.0.1:3000/dashboard/evaluation-tasks/cmunznt6d001zbxi8x06xa07u/results)。如果显示登录页，按 [本机部署说明](E:/...AAAAIIIIIAIPM/个人项目/Eval-Any-Agent-source-20260929/Eval-Any-Agent/本机部署.md) 登录。

1. 点击页面上的 **开始复核**，优先打开 AI 未通过且尚未复核的用例。也可以在每一行点击 **人工复核**，自行选择 C08、C09 等用例。
2. 对照商品原图、生成成品、本条要求和 AI 理由。点击方向名称切换成品；**查看大图**可放大核对包装文字。没有图片的边界用例，展开 **查看输入与输出记录**，核对错误码和执行结果。
3. 选择 **判对了 / 判错了 / 暂时无法判断**，填写依据，再点击 **保存复核**。窄屏可以点击顶部 **填写判断** 直接跳转；键盘焦点会移到判断选项，接着按 Tab 可填写理由。

“判对了”表示你认为 AI 对该条结果的判断正确，既可以是正确通过，也可以是正确拒绝。“判错了”表示评分、理由或通过结论有误；可以选填人工分数及应当通过/未通过。缺乏证据时选择“暂时无法判断”，写明还需要什么材料。

保存后可在 **复核历史** 查看账号、时间、理由和每次改判。再次复核会追加记录。表格支持待复核、已复核及三种判断筛选，CSV / XLSX 包含最新人工结论及完整历史。
