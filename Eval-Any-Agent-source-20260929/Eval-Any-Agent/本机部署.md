# Eval-Any-Agent 本机部署

- 登录地址：http://127.0.0.1:3000/login
- 管理员用户名：`admin`
- 管理员密码：见 `.local/登录信息.txt`
- 启动：双击 `启动测评工具.cmd`
- 停止：双击 `停止测评工具.cmd`

服务以生产模式在本机后台运行。电脑重启后，双击启动文件恢复服务。

数据库位于 `prisma/dev.db`，配置位于 `.env`。备份时先停止服务，再复制这两个文件及相关数据库辅助文件。日志位于 `.local/server.stdout.log` 和 `.local/server.stderr.log`。

初始环境为空。上传 CSV 或 XLSX 数据集后，在配置中心创建被测接口，并配置评分模型和评估器，即可执行评测。

本机当前已有真实评测数据。2026-09-30 增加了结果页的 **人工复核**：查看原图/成品与 AI 理由、保存判断和理由、保留历史，并随 CSV/XLSX 导出。详见 [人工复核使用说明](E:/...AAAAIIIIIAIPM/个人项目/Eval-Any-Agent-source-20260929/Eval-Any-Agent/人工复核使用说明.md)。
