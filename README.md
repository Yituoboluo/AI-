# 造物营 — AI 营销素材 MVP

独立产品项目。主流程：上传商品图 → 自动抠图 → 选择一套或三套独立方向 → 可选自定义 → 一键生成样稿 → 修改文案 / 下载 PNG。保留旧版事实卡、双尺寸与人工审核流程供旧项目使用。完整框架包含首页、AI 图片、AI 页面、AI 文案、AI 视频、AI 工具箱、AI 字体、我的素材、任务中心、审核和账户设置。

## 当前实现

- 千问文案接口：依据确认卖点，输出三个 1–18 字候选；模型输出校验后展示，用户采纳才修改素材。
- 图片创作：上传后浏览器 U2NetP 自动抠图；自定义背景、文案与排版默认收起。默认生成三套独立方向，也可先试一套：千问视觉完成一次规划，再按所选方向分别调用图片模型。场景融合路线将商品与场景整合到生成图中，成品保留该底图中的商品；其他路线使用抠出的商品与背景合成。
- 自动文案使用视觉风格短句，不从图片推断品牌或商品功能；名称和卖点可自定义。图片模型结果与成品 PNG 均存入云端，修改文案复用已有底图与商品，不再次调用模型。
- 抠图首次约下载 16 MB，模型在浏览器 Web Worker 中运行。保留原图，可比较边缘、下载透明 PNG、失败重试或改用原图。透明玻璃、细毛发与复杂多主体仍需人工检查。
- Vercel 独立部署使用邮箱密码登录、Turso 保存账号/会话/项目/任务、私有 Vercel Blob 保存商品图与成品。原 Sites 的 D1/R2 运行方式仍保留。服务器检查会话、来源、账户归属和保存版本。
- 本机 IndexedDB 按账号隔离，未登录的本机工作区单独保存。登录、退出和跨标签页切号会先保存本机修改，再重新载入对应工作区；匿名和旧版草稿不会自动同步到新账号。备份会打包图片内容。
- 任务状态、模型名、供应商返回用量、采纳/弃用及原因；审核和导出事件。金额以供应商账单为准，没有虚构收益数据。
- 草稿软删除、撤销与最近删除恢复；云端生命周期使用版本校验，旧页面不能复活删除记录。新建不再预置示例商品。
- 页面、视频、创意字等工具提供需求、参数与预览框架，保存需求后可回来继续，不伪造生成。
- 产品范围为 PC Web、六类共 12 个工具入口；证件照与 AI 图标已按用户要求取消，不再保留待开发入口。
- 调用默认关闭。未配置密钥、额度、账户模型权限时不能真实生成。没有自动重试。

## 本地运行

需要 Node.js 24（开发数据库使用 node:sqlite）。

```sh
npm ci
npm run dev
```

访问 http://127.0.0.1:4173 。开发数据在 `.local/`，仅监听 loopback；开发专用身份不会进入生产构建。

```sh
npm test
npm run build
```

`npm run dev` 使用原本的本地开发身份及 `zaowu-studio` 数据库，用于无登录服务的兼容预览。Vercel 生产站点使用下面的独立账号流程。

`public/` 为界面源文件；`server/worker.mjs` 为共用业务 API，`server/vercel-*.mjs` 为独立部署适配；`db/schema.ts` 和 `drizzle/` 为业务数据库定义与迁移，`server/vercel/*.sql` 为认证/上传迁移；`dist/` 为 Sites 构建产物，`dist-vercel/` 为 Vercel 静态构建产物。

## Vercel 独立部署

需要 Node.js 24、一个 Turso 数据库，以及一个 **Private** Vercel Blob 存储。浏览器先授权直传图片，再由 API 校验文件大小、魔数、内容哈希和归属；项目及排版保存只发送素材引用。私有图片通过当前账号的同源 API 读取，可用于 Canvas 预览与 PNG 导出。

1. 在 Vercel 中导入此 Git 仓库，项目 Node.js 版本设为 24。仓库中的 `vercel.json` 已指定构建命令、静态输出目录、API 路由和 300 秒函数上限。
2. 创建并连接 Turso 与私有 Blob。将 `TURSO_DATABASE_URL`、`TURSO_AUTH_TOKEN`、`BLOB_READ_WRITE_TOKEN` 和模型供应商密钥配置为 Vercel 服务端环境变量；按实际用途选择 Production / Preview 环境范围。
3. 配置 `AUTH_REGISTRATION_MODE=invite`，将随机生成的高强度邀请码保存为敏感变量 `AUTH_INVITE_CODE`。邀请码仅通过私下渠道交给受邀用户，不写入前端、文档或 Git。
4. 本机复制 `.env.example` 为 `.env.local` 并填写相应服务端变量，用于显式应用数据库迁移。`.env.local` 已忽略，不提交。运行以下检查与迁移后部署：

```sh
npm ci
npm test
npm run build:vercel
npm run db:migrate:vercel
npx vercel --prod
```

也可使用已连接 Git 的 Vercel 项目自动构建。数据库迁移需在新代码启用前单独执行，API 请求和冷启动不会自动建表。迁移记录保存在 `_vercel_schema_migrations`，重复执行安全；已应用的迁移文件不能原地改写，应新增迁移文件。

Vercel 环境变量修改后需要重新部署。模型默认关闭；真实生成前须显式设置 `AI_ENABLED=true`、密钥与每日额度。生产日志及 API 不返回密码、密码摘要、邀请码或 Blob 私有地址。

### 注册、登录与账号隔离

打开站点右上角“登录 / 注册”，切换到注册，填写邮箱、12–128 个字符的密码与管理员提供的邀请码。邮箱会去掉首尾空格并统一为小写；注册成功后直接登录。邀请码轮换后只影响后续注册，已存在的账号仍使用邮箱密码登录。

注册模式可以设为 `invite`（默认，仅凭邀请码注册）、`open`（开放注册）或 `disabled`（停止新注册，已有账号仍可登录）。`invite` 模式缺少邀请码配置时注册会拒绝。此版本不提供邮件验证、短信或邮件找回，忘记密码由管理员在本机重置。

会话 cookie 使用 `__Host-`、Secure、HttpOnly、SameSite=Lax 与 Path=/，默认有效期 7 天。数据库只存随机会话令牌的 SHA-256 摘要，密码存随机盐与异步 scrypt 摘要。登录/注册按 IP 和规范化邮箱在共享数据库中限流，默认 15 分钟内分别最多 30 / 10 次；多个部署实例及浏览器会话共用计数。

独立部署不接受客户端提供的 `oai-*` 身份头。业务请求携带当前账号的 `X-Zaowu-Workspace`，账号已切换时返回 `WORKSPACE_CHANGED`；前端暂停旧页面的云端操作并重新载入，不自动重发收费生成。

### 管理员重置密码

管理员在可信电脑上使用对应数据库的 `.env.local`，在交互式终端运行：

```sh
node --env-file=.env.local scripts/reset-password.mjs account@example.com
```

终端会两次提示输入新密码，输入不回显。密码不放在命令参数中。成功后该账号所有现有会话立即失效，用户需用新密码重新登录；账号 ID、项目及素材保持不变。此命令只连接数据库，没有公开的重置密码接口。

### 从旧站或匿名工作区导入

在旧版 Sites 站点或未登录的本机工作区打开“账户设置”，点击“导出工作区备份”。在新站登录目标账号后，打开相同页面点击“导入备份”，逐份导入导出的 JSON 文件。备份包含原图与背景；大工作区可能拆成多个文件，需要全部保留并分别导入。

导入会新建创作副本，使用前需重新审核。旧站数据仍保留；新账号不会根据旧身份头猜测归属，也不会自动绑定旧 D1/R2 数据。需要服务器级迁移时，必须先取得完整的数据导出和经核验的账号映射。

## 启用模型

本地兼容预览复制 `.env.example` 为 `.env`，Vercel 管理命令使用 `.env.local`，在本机填写密钥。不要把密钥写进前端、Git、项目文档或聊天。生产配置使用对应平台的敏感环境变量，更新后部署才生效。

| 环境变量 | 用途 |
| --- | --- |
| DASHSCOPE_API_KEY | 百炼按量付费服务端密钥，生产标记为 secret；不进入前端 |
| QWEN_REGION | cn-beijing（默认）或 ap-southeast-1，须与密钥地域匹配 |
| QWEN_WORKSPACE_ID | 可选，业务空间专属域名；留空用对应地域现有域名 |
| QWEN_TEXT_MODEL | 默认 qwen-plus |
| QWEN_VISION_MODEL | 新版品类创作默认 qwen3-vl-plus；旧版兼容路径默认 qwen-vl-plus，可统一覆盖 |
| QWEN_VISION_TIMEOUT_MS | 仅视觉规划的等待期限，默认 60000 毫秒；只接受 60000–90000 的安全整数，非法或超界值回到默认值。本 Vercel 部署设为 90000 |
| QWEN_IMAGE_MODEL | 默认 qwen-image-plus-2026-01-09，同步文生图 |
| COPY_PROVIDER / IMAGE_PROVIDER | qwen；旧 DeepSeek/Seedream 适配保留供迁移 |
| AI_ENABLED | 默认 false；明确开启才会发起调用 |
| AI_COPY_DAILY_LIMIT | 文案每日调用尝试次数，默认 0 |
| AI_IMAGE_DAILY_LIMIT | 默认 0 关闭；设为 unlimited 不限每日次数。一套或三套独立样稿分别预留 1 或 3 次，实际费用以服务商调用为准 |

视觉规划的两条路径共用 `QWEN_VISION_TIMEOUT_MS`，默认等待 60 秒；本 Vercel 部署等待 90 秒，为后续最多 180 秒的生图请求及保存留出余量，函数总上限仍为 300 秒。原 Sites 未设置该变量时保留 60 秒。此参数不改变文案或生图的等待期限，也不自动重试：超时仍记录为结果未确认，供应商可能已执行并计费。

快捷创作每次包含一次视觉规划，再按所选的一个或三个独立方向分别生成图片，预留 1 或 3 次应用图片额度；视觉 tokens 单独记录，视觉规划与图片生成均可能产生供应商费用。每套样稿使用对应方向的生成图，修改文案复用已有底图。次数按账户、UTC 日期分别计算，单账户同时最多两个待执行/执行中任务。失败和结果未确认的尝试也占额度，不能把次数上限视为人民币硬预算；还需在供应商侧设置额度/余额控制。密钥及模型权限必须通过真实调用验证，代码接入不等于已经实测成功。

## 验证与已知边界

`npm test` 运行原有 88 项业务测试及新增独立部署测试，不产生模型费用。覆盖身份隔离、跨站写入、图片归属、版本冲突、默认关闭、额度、幂等执行、源资料过期、超时、输出校验和错误脱敏，以及质量反馈、图片方向和 Langfuse 追踪。新增测试验证独立注册/登录、共享限流、会话撤销、密码重置并发、账号本机隔离、libSQL 事务、私有 Blob 与签名上传回调；自动测试不能替代真实部署的完整流程验收。

2026-09-23 已使用用户确认的北京地域密钥完成真实调用：连接探测、三个文案候选，以及两次背景生成与 PNG 下载。首次背景误生成商品主体，已移除正向提示中的商品名称并增加反向约束；第二次返回空背景，仍需人工检查场景道具与构图。2026-09-23 实测期间的平台配置为每日文案 5 次、图片 2 次，当时该部署的用户无需填写密钥。

后续效果评估：用 5 个真实商品记录首稿时间、可采纳率、失败原因，核对供应商账单。没有真实实验前不填写提效比例或商业收益。

生成请求当前依赖浏览器保持连接；关闭页面可能导致任务中断。状态超过六分钟未确认会提示结果不确定，不自动补发收费调用。每个账户最近 60 个任务可在界面查询。后台独立队列、团队角色、视频生成、自动法规审核与投放闭环不在首版范围。

AI 背景保留供应商水印设置，成品需人工检查事实、文字、商品边缘与排版。现阶段是当前技术条件下完成的独立项目，不能作为 2024–2025 年任职或上线业绩的证明。
