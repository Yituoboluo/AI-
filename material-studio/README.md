# 造物营 — AI 营销素材 MVP

独立产品项目。主流程：上传商品图 → 自动抠图 → 可选自定义 → 一键生成 → 两种排版 → 修改文案 / 下载 PNG。保留旧版事实卡、双尺寸与人工审核流程供旧项目使用。完整框架包含首页、AI 图片、AI 页面、AI 文案、AI 视频、AI 工具箱、AI 字体、我的素材、任务中心、审核和账户设置。

## 当前实现

- 千问文案接口：依据确认卖点，输出三个 1–18 字候选；模型输出校验后展示，用户采纳才修改素材。
- 图片创作：上传后浏览器 U2NetP 自动抠图；自定义背景、文案与排版默认收起。只传图片也能生成：千问视觉选择背景与视觉风格，再调用一次图片模型生成背景，保留抠出的原商品合成两种排版。
- 自动文案使用视觉风格短句，不从图片推断品牌或商品功能；名称和卖点可自定义。图片模型结果与合成 PNG 均存入云端，修改文案复用背景与商品，不再次调用模型。
- 抠图首次约下载 16 MB，模型在浏览器 Web Worker 中运行。保留原图，可比较边缘、下载透明 PNG、失败重试或改用原图。透明玻璃、细毛发与复杂多主体仍需人工检查。
- 当前登录账户的项目元数据和任务存入 D1，商品图片、预览和生成背景存入 R2。服务器检查身份、来源、账户归属和保存版本。
- 本机 IndexedDB 缓存、旧草稿手动同步、离线待同步、冲突时另存本机副本。备份会打包图片内容。
- 任务状态、模型名、供应商返回用量、采纳/弃用及原因；审核和导出事件。金额以供应商账单为准，没有虚构收益数据。
- 草稿软删除、撤销与最近删除恢复；云端生命周期使用版本校验，旧页面不能复活删除记录。新建不再预置示例商品。
- 页面、视频、创意字等工具提供需求、参数与预览框架，保存需求后可回来继续，不伪造生成。
- 产品范围为 PC Web、六类共 12 个工具入口；证件照与 AI 图标已按用户要求取消，不再保留待开发入口。
- 调用默认关闭。未配置密钥、额度、账户模型权限时不能真实生成。没有自动重试。

## 本地运行

需要 Node.js 24（开发数据库使用 node:sqlite）。

```sh
npm install
npm run dev
```

访问 http://127.0.0.1:4173 。开发数据在 `.local/`，仅监听 loopback；开发专用身份不会进入生产构建。

```sh
npm test
npm run build
```

`public/` 为界面源文件；`server/` 为 Cloudflare Worker API；`db/schema.ts` 为数据库定义，`drizzle/` 为生成的迁移；`dist/` 为构建产物。

## 启用模型

本地复制 `.env.example` 为 `.env`，在本机填写密钥。不要把密钥写进前端、Git、项目文档或聊天。生产配置使用 Sites 的 secret 环境变量，更新后部署才生效。

| 环境变量 | 用途 |
| --- | --- |
| DASHSCOPE_API_KEY | 百炼按量付费服务端密钥，生产标记为 secret；不进入前端 |
| QWEN_REGION | cn-beijing（默认）或 ap-southeast-1，须与密钥地域匹配 |
| QWEN_WORKSPACE_ID | 可选，业务空间专属域名；留空用对应地域现有域名 |
| QWEN_TEXT_MODEL | 默认 qwen-plus |
| QWEN_VISION_MODEL | 新版品类创作默认 qwen3-vl-plus；旧版兼容路径默认 qwen-vl-plus，可统一覆盖 |
| QWEN_IMAGE_MODEL | 默认 qwen-image-plus-2026-01-09，同步文生图 |
| COPY_PROVIDER / IMAGE_PROVIDER | qwen；旧 DeepSeek/Seedream 适配保留供迁移 |
| AI_ENABLED | 默认 false；明确开启才会发起调用 |
| AI_COPY_DAILY_LIMIT | 文案每日调用尝试次数，默认 0 |
| AI_IMAGE_DAILY_LIMIT | 默认 0 关闭；设为 unlimited 不限每日次数。三套独立样稿预留 3 次，实际费用以服务商调用为准 |

快捷创作每次包含一次视觉分析和一次背景生成，占用一次应用图片额度；视觉 tokens 单独记录，两者均可能产生供应商费用。两张成品是同一背景的两种排版。次数按账户、UTC 日期分别计算，单账户同时最多两个待执行/执行中任务。失败和结果未确认的尝试也占额度，不能把次数上限视为人民币硬预算；还需在供应商侧设置额度/余额控制。密钥及模型权限必须通过真实调用验证，代码接入不等于已经实测成功。

## 验证与已知边界

当前通过 29 项自动化测试；这些测试使用替身，不产生模型费用。覆盖身份隔离、跨站写入、图片归属、版本冲突、默认关闭、额度、幂等执行、源资料过期、超时、输出校验和错误脱敏。

2026-09-23 已使用用户确认的北京地域密钥完成真实调用：连接探测、三个文案候选，以及两次背景生成与 PNG 下载。首次背景误生成商品主体，已移除正向提示中的商品名称并增加反向约束；第二次返回空背景，仍需人工检查场景道具与构图。平台配置为每日文案 5 次、图片 2 次，用户无需填写密钥。

后续效果评估：用 5 个真实商品记录首稿时间、可采纳率、失败原因，核对供应商账单。没有真实实验前不填写提效比例或商业收益。

生成请求当前依赖浏览器保持连接；关闭页面可能导致任务中断。状态超过六分钟未确认会提示结果不确定，不自动补发收费调用。每个账户最近 60 个任务可在界面查询。后台独立队列、团队角色、视频生成、自动法规审核与投放闭环不在首版范围。

AI 背景保留供应商水印设置，成品需人工检查事实、文字、商品边缘与排版。现阶段是当前技术条件下完成的独立项目，不能作为 2024–2025 年任职或上线业绩的证明。
