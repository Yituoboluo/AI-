# 造物营 PRD 待确认项（Skill标准版）

版本：V1.0.0｜2026-10-01｜配套《造物营产品需求文档（PRD）》

本清单由 pm-prd-writer 从 PRD 中提取假设与未确认事项。默认建议是评审提案，不表示已经批准；这些事项不阻塞PRD交付。项目当前人工视觉评分0/29、正式评分复核0/12、真实回归0是已有事实，需要实际执行才能改变，不以确认清单替代执行。

## 必须确认（影响价值结论或扩大试用）

### D01 用户价值证据（假设 H01）

- 关联：概述／背景介绍、用户目标、E08。
- 未确定：商家与设计师的旧方案、实际返工和节省工时是否支持产品价值。
- 默认建议：选择核心商家或设计任务，记录同任务旧流程、AI流程、修改时间及采用；补用户原话与素材来源。现阶段不写效率增长、转化或ROI结论。
- 影响：若缺证据，可继续开发与课程评审，但不能宣布商业价值已验证。
- 确认负责人／时点：项目负责人及参与用户；价值报告前。

### D03 调用额度、现金预算与告警

- 关联：产品目标、执行与恢复（F05）、统计与系统集成。
- 未确定：试用账户UTC每日调用限额、真实现金预算、失败／重试计费核对责任人。
- 默认建议：维持已授权额度，不自动增加付费调用；明确一次重试会产生新调用，先核对未知原结果。缺账单时成本显示null／未测。
- 影响：阻塞扩大付费试用及真实成本判断；不阻塞当前文档和既有证据整理。
- 确认负责人／时点：项目负责人；扩大付费试用前。

### D04 数据保留、永久清理和追踪隐私

- 关联：非功能／安全、数据库与生命周期、追踪。
- 未确定：原图、成品、失败证据、反馈与复核历史保存周期；永久删除范围、备份责任和外部追踪最小数据集。
- 默认建议：试用期保留完整验收证据、项目软删除可恢复；永久清理前核对备份和目标范围。外部追踪不发送密钥、无必要图片或个人信息。
- 影响：阻塞扩大试用后的生命周期承诺和自动清理；不将软删除误当永久擦除。
- 确认负责人／时点：项目负责人及维护者；扩大试用前。

## 建议确认（影响试用验收和完整度）

### D02 试用目标和灰度（含假设 H02）

- 关联：概述／产品目标、版本规划、性能与可靠性。
- 未确定：参与者、正向任务数量、首次可用率目标及扩大条件。
- 默认建议：先内部和少量账户；至少20个正向任务作初步观察；首次可用率≥70%作为试用目标候选；P0商品裁切与像素约束问题未关闭时暂停扩大。20例不证明统计显著，也不是课程规定。
- 影响：影响试用通过判定与预算；已有本批数据不改写为达到该目标。
- 确认负责人／时点：项目负责人；试用启动前。

### D05 性能、兼容、容量与回滚

- 关联：全局交互、性能与可靠性、M2。
- 未确定：浏览器与分辨率、非模型交互目标、平台总并发及生产回滚操作。
- 默认建议：Chrome/Edge当前稳定版，1920×1080及1366×768；本地编辑P95≤1秒、非模型元数据P95≤3秒作为验收建议；模型耗时单独统计。先实测少量账户容量，确认回滚版本和数据兼容。
- 影响：影响兼容和试用可靠性标准；这些值尚未实测，不能宣称已满足SLA。
- 确认负责人／时点：项目负责人、研发和测试；试用启动前。

## 可后续补充（当前范围已收窄）

### D06 团队角色与内容平台后续范围

- 关联：角色及权限、F14、七个框架工具。
- 未确定：团队成员权限、审批、批量SKU、图文／视频编排的独立版本范围。
- 默认建议：本版按单账户所有权，业务上的创作者／评审者可由同一人承担；团队RBAC及审批后续独立设计。七个框架保持需求保存与示意，不承诺真实生成。
- 影响：不阻塞本版；若试用改为跨成员协作，必须先完成数据授权与新的验收。
- 确认负责人／时点：产品负责人；对应后续版本立项前。
